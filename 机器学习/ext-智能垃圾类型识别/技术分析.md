# 智能垃圾类型识别：模型训练文件与技术分析

本目录提供一份**可复现实验的垃圾分类（图像分类）模型训练脚本**：`train_garbage_classifier.py`，用于完成“垃圾类别识别/分类”任务（不同垃圾类别的图片 → 输出类别）。

> 说明：SmartFruits 主项目的视觉识别模块以 YOLOv5 目标检测为主；但“智能垃圾分类”在报告与课程实验里更常以**图像分类**建模（每张图片对应一个垃圾类别），所以这里采用 **PyTorch + torchvision 的迁移学习分类方案**，更适合写训练报告、对比实验与部署到轻量设备。

---

## 1. 任务定义与数据组织

### 1.1 任务定义
- **输入**：一张垃圾图像（如纸张、塑料、金属、玻璃、厨余等）。
- **输出**：所属垃圾类别 \(y \in \{0,1,\dots,C-1\}\)。
- **学习目标**：最小化分类损失（交叉熵），提升验证集准确率，并在测试/实际使用中具备泛化能力。

### 1.2 推荐的数据目录结构（ImageFolder）
训练脚本使用 `torchvision.datasets.ImageFolder`，因此数据集目录建议如下：

```
your_dataset/
  train/
    plastic/
      xxx.jpg
    paper/
      yyy.jpg
  val/
    plastic/
      a.jpg
    paper/
      b.jpg
```

其中：**每个子文件夹名 = 类别名**，脚本会自动生成 `classes.json` 记录类别索引映射。

## 2. 模型训练算法设计（迁移学习）

### 2.1 为什么使用迁移学习（Transfer Learning）
垃圾分类常见问题：
- 数据量较小、采集场景复杂（光照、背景、遮挡、拍摄角度变化）。
- 直接从零训练会过拟合且收敛慢。

迁移学习做法：
- 使用在 ImageNet 上预训练的 backbone（如 ResNet / MobileNet / EfficientNet）作为特征提取器。
- 将最后的分类层替换为本任务类别数 \(C\)，再进行微调训练。

优势：
- **更快收敛**、**更高起点**、对小数据更稳。

### 2.2 网络结构选择
脚本提供三种可选 backbone：
- `resnet18`：训练稳定、速度适中，适合报告对比与基线模型。
- `mobilenet_v3_small`：参数量小，适合边缘端/嵌入式部署。
- `efficientnet_b0`：精度潜力更高，训练成本略高。

在报告中可做对比实验：不同 backbone 的参数量、速度、准确率差异。

## 3. 数据预处理与增强（提升泛化）

训练阶段增强（`RandomResizedCrop` + `HorizontalFlip` + `ColorJitter`）的目的：
- 模拟不同拍摄距离/角度：随机裁剪与缩放。
- 模拟左右视角变化：水平翻转。
- 模拟光照/色彩变化：亮度/对比度/饱和度扰动。

验证阶段仅做 `Resize + CenterCrop`，避免引入随机性，保证指标可对比。

同时使用 ImageNet 的均值方差做 `Normalize`，与预训练权重保持一致。

---

## 4. 损失函数、优化器与学习率策略

### 4.1 损失函数：交叉熵（Cross Entropy）
对单标签多分类任务，最常用：
\[
\mathcal{L} = - \sum_{i=1}^{C} y_i \log p_i
\]

脚本支持 `label_smoothing`（标签平滑）：
- 作用：降低模型过度自信，缓解小数据过拟合，提升泛化。
- 建议范围：0～0.2（常用 0.05/0.1）。

### 4.2 优化器：AdamW
选择原因：
- Adam 的自适应学习率带来更快收敛；
- W（decoupled weight decay）更适合与正则化结合。

### 4.3 学习率调度：CosineAnnealingLR
余弦退火策略在中小规模分类任务里表现稳健：
- 前期较大学习率快速下降损失；
- 后期小学习率细致收敛，提高验证集性能。

## 5. 训练流程与工程化细节（报告可写点）

训练脚本 `train_garbage_classifier.py` 做了这些工程化设计：
- **固定随机种子**：保证可复现；
- **自动保存实验配置**：`config.json`（便于写报告与复现实验）；
- **保存权重**：
  - `checkpoints/last.pt`：最后一轮
  - `checkpoints/best.pt`：验证集准确率最优
- **早停（Early Stopping）**：验证集连续 `patience` 轮未提升则停止，避免过拟合与浪费算力；
- **混合精度 AMP（可选）**：在 CUDA 上可加速并降低显存占用；
- **训练日志**：`metrics.csv` 记录每轮 train/val loss、acc、学习率与耗时；
- **混淆矩阵**：训练结束后输出 `confusion.npy`，便于分析“哪些类别容易混淆”。

## 6. 评价指标与分析方法（报告重点）

### 6.1 指标
- **Top-1 Accuracy**：最直观的分类正确率。
- （可选扩展）Precision/Recall/F1：对“某类垃圾很少”或误判代价高的场景更有意义。

### 6.2 混淆矩阵分析
混淆矩阵可以回答：
- 哪些类别外观相似（如透明塑料 vs 玻璃）导致混淆？
- 是否存在标注质量问题或类别定义边界不清？

建议在报告里展示：
- 典型混淆样本截图
- 改进思路：补数据、细分类别、引入分割/检测辅助等

## 7. 如何运行训练（写在报告/答辩 PPT 也好用）

在项目根目录（SmartFruits）下执行：

```bash
python 机器学习/ext-智能垃圾类型识别/train_garbage_classifier.py \
  --data-dir /path/to/your_dataset \
  --arch resnet18 \
  --epochs 30 \
  --batch-size 32 \
  --img-size 224 \
  --lr 3e-4 \
  --weight-decay 1e-4 \
  --label-smoothing 0.05 \
  --patience 7 \
  --amp
```

训练输出会在：
- `机器学习/ext-智能垃圾类型识别/runs_garbage/日期时间/`

其中最重要的是：
- `checkpoints/best.pt`
- `classes.json`
- `metrics.csv`

## 8. 可能的改进方向（加分项）

- **数据层面**：补充不同光照/背景/遮挡场景；平衡各类别样本数（或使用重采样/类别权重）。
- **模型层面**：尝试 EfficientNet-B0、加入 Dropout、尝试更强的数据增强（RandAugment/MixUp/CutMix）。
- **训练层面**：学习率 warmup、冻结 backbone 前几层再逐步解冻、K-fold 交叉验证。
- **任务升级**：若一张图里包含多种垃圾或需定位垃圾位置，建议使用目标检测（如 YOLO 系列）或分割模型。
